# portfolio

A one page personal site I put together in Bootstrap 5 at the end of 2022, under the name Vora Vision. Static HTML with no build step. Bootstrap and Bootstrap Icons are vendored into `css/` and `js/`, and the contact section loads a Mapbox GL map.

It never got finished. The FAQ and the services blurbs are still lorem ipsum, the Visions section has an empty `<img>`, `app.js` is an empty file, and the map is centered on coordinates in Boston while the contact list says Austin. Last touched January 2023.
